# SLAM 기반 미지 환경 자율 탐색 및 목표물 발견·복귀 로봇

**HYPER Robotics | 1팀**

ROS 2, Gazebo, SLAM, Frontier Exploration, Nav2를 활용하여 사전 지도가 없는 미로 환경을 로봇이 스스로 탐색하고, 지정된 목표물을 발견하면 출발 지점으로 자율 복귀하는 시스템을 구현하는 프로젝트입니다.

---
### 1. 프로젝트 개요
일반적인 SLAM 실습에서는 사람이 키보드로 로봇을 직접 조작하며 주변 환경의 지도를 생성합니다.

본 프로젝트에서는 여기서 한 단계 더 나아가, 로봇이 생성한 지도를 분석하여 아직 탐색하지 않은 공간을 스스로 찾고, 다음 이동 위치를 결정하며, 목표물 발견 후 자율적으로 복귀하도록 구현합니다.

#### 핵심 목표

- **지도 생성:** SLAM을 활용한 미지 환경 지도 생성 및 로봇 위치 추정
- **자율 탐색:** Frontier Exploration을 이용한 미탐색 영역 탐색 및 다음 이동 목표 선정
- **자율 이동:** Nav2를 활용한 경로 계획 및 장애물 회피
- **목표물 탐지:** 미로 내부에 배치된 지정 목표물 발견
- **자율 복귀:** 목표물 발견 시 탐색을 종료하고 출발 지점으로 복귀

#### 개발 환경

- 시뮬레이터: Gazebo
- 로봇: TurtleBot3
- 운영체제: Ubuntu (VM 기반)
- 로봇 소프트웨어: ROS 2 Jazzy
- 주요 센서: LiDAR, 카메라 또는 가상 탐지 센서

※ 시뮬레이션 기반 개발을 중심으로 진행하며, 실제 로봇 적용 여부는 프로젝트 범위에 포함되지 않습니다.

---
### 2. 전체 동작 과정
**STEP 1. 시뮬레이션 환경 구성**

- SDF 파일을 이용해 미로 환경 제작
- Gazebo에 TurtleBot3 배치
- LiDAR 및 주행 센서 구성

**STEP 2. SLAM 기반 지도 생성**

- LiDAR를 이용해 주변 환경 관측
- SLAM Toolbox로 지도 생성
- 로봇의 이동에 따라 지도 갱신

**STEP 3. Frontier Exploration 기반 자율 탐색**

- SLAM이 생성한 Occupancy Grid 분석
- 탐색된 공간과 미탐색 공간의 경계인 Frontier 추출
- 여러 Frontier 중 다음 탐색 목표 선정
- 선정한 좌표를 Nav2에 전달
- 목표 지점까지 이동 후 지도 갱신
- 새로운 Frontier를 찾아 탐색 반복

**STEP 4. 목표물 발견**

- 탐색 도중 카메라 또는 가상 센서로 목표물 탐지
- 목표물 발견 여부 판단
- 목표물 발견 시 탐색 중단

**STEP 5. 출발 지점 복귀**

- 탐색 시작 시 저장한 출발 위치 활용
- Nav2에 출발 위치를 목표로 전달
- 생성된 지도를 이용해 복귀 경로 계획
- 출발 지점 도착 시 임무 종료

### 3. 주요 구현 기능

| 기능 | 구현 방향 |
|---|---|
| 미로 환경 생성 | Gazebo SDF 직접 제작 |
| TurtleBot3 시뮬레이션 | 기존 로봇 모델 활용 |
| 지도 생성 | SLAM Toolbox 활용 |
| 자율 이동 | Nav2 활용 및 설정 |
| Frontier 기반 자율 탐색 | 기존 Frontier Exploration 패키지 활용 및 연동 |
| Frontier 알고리즘 | Occupancy Grid 분석, Frontier 추출 및 목표 선정 노드 직접 구현 |
| 탐색 반복 제어 | 목표 전송, 도달 확인 및 예외 처리 |
| 목표물 탐지 | 카메라 또는 가상 센서 활용 |
| 자율 복귀 | 탐색 중단 및 Nav2 복귀 명령 연동 |

#### Frontier Exploration 구현 방향

먼저 기존 Frontier Exploration 패키지를 활용하여 SLAM–Frontier–Nav2가 연동된 자율 탐색 시스템을 구현하고, 전체 동작을 검증합니다.

이후 기존 패키지의 구조와 동작 방식을 참고하여 Frontier 탐색 노드를 직접 구현하는 것을 목표로 합니다.

직접 구현할 주요 기능은 다음과 같습니다.

1. **Occupancy Grid 분석:** 탐색된 공간과 미탐색 공간 구분
2. **Frontier 추출 및 그룹화:** 탐색 가능한 경계 영역 탐색
3. **탐색 목표 선정:** 여러 Frontier 후보 중 다음 이동 목표 결정
4. **Nav2 연동 및 반복 탐색:** 목표 좌표 전달 및 탐색 반복
5. **예외 처리:** 도달 불가능한 목표 제외, 중복 탐색 방지 등

기존 패키지를 활용한 자율 탐색과 직접 구현한 Frontier 노드의 동작을 비교하고, 필요에 따라 탐색 효율을 개선합니다.
