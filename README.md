# maze_escape — SLAM 기반 미로 탐색과 카메라 열쇠·문 제어

TurtleBot3가 SLAM 지도를 만들고 직접 구현한 프론티어 알고리즘으로 미지 영역을 탐색하는 프로젝트야.
카메라 영상으로 열쇠 대용 물체를 찾아 획득한 뒤 문을 여는 기능을 추가했어.

## 현재 진행 상황

| 기능 | 확인 상태 |
|---|---|
| 팀 미로에서 TurtleBot3 실행 | 우분투 VM에서 실행 확인 |
| SLAM 지도 생성 | 정상적으로 그려지는 것 확인 |
| Nav2 왕복 이동 | 두 목표 이동 성공 |
| 직접 구현한 프론티어 추출·선택·반복 탐색 | 목표 10개 연속 도착 성공 |
| 카메라 열쇠 인식·획득·문 열기 | 코드 구현 및 로직 검사 완료, 실제 가제보 통합 실행 확인 필요 |

목표 10개 도착을 전체 미로 탐색 완료로 판정하지 않아.
로직·설정 검사 44개가 통과했으며, ROS 통신을 가짜 객체로 대체한 검사도 포함돼.
이 검사는 실제 카메라 렌더링과 물리 주행 성공을 뜻하지 않아.

## 개발 환경

- Ubuntu 24.04 / ROS 2 Jazzy / Gazebo Harmonic
- TurtleBot3 Burger / SLAM Toolbox / Nav2
- Python 3.12, NumPy, OpenCV, PyYAML
- VMware 기반 개발

## 설치와 실행

필요한 ROS·가제보·TurtleBot3 패키지가 설치된 우분투에서 실행해.
저장소 폴더 이름을 `~/maze_escape`로 두면 상세 안내의 경로를 그대로 사용할 수 있어.
이 저장소 안에서 실행하는 명령은 실제 폴더 위치를 자동으로 찾도록 되어 있어.

```bash
cd ~/maze_escape
bash setup.sh
```

`setup.sh`는 설치된 패키지를 확인하고, 프로젝트의 `models/camera_burger` 안에 RGB-D 카메라 로봇을 만들어.
설치된 로봇 모델과 바퀴·마찰·주행 물리 설정은 수정하지 않아.

각각 별도 터미널에서 실행하고, 앞 단계가 준비된 뒤 다음으로 넘어가.

| 터미널 | 명령 | 역할 |
|---|---|---|
| 1 | `bash run/01_sim.sh` | 가제보 미로·카메라 로봇·센서 연결 |
| 2 | `bash run/02_slam.sh` | SLAM 지도 생성 |
| 3 | `bash run/03_nav2.sh` | 자율 이동 |
| 4 | `bash run/04_rviz.sh` | 지도·로봇·카메라 화면 |
| 5 | `bash run/05_probe.sh` | 짧은 왕복 이동 시험 |

왕복 시험을 통과하면 같은 터미널 5에서 아래 중 필요한 프로그램을 하나 실행해.

```bash
# 프론티어 표시 확인: 종료할 때 Ctrl+C
bash run/06_frontiers.sh

# 프론티어 자동 탐색만 시험
bash run/07_explore.sh

# 카메라로 열쇠 획득 후 문 열기
bash run/08_camera_escape.sh
```

06·07·08을 동시에 실행하지 않아. 자세한 준비·종료 방법은 아래 문서에 있어.

- [처음 실행하기](처음_실행하기.md)
- [카메라 열쇠 인식과 문 열기](카메라_열쇠와_문_실행하기.md)

## 카메라 임무

현재 미로는 **노란색 블록을 열쇠 대용 물체**, **빨간색 벽을 문**으로 사용해.
미로 안의 물체 이름 `red_key`와 실제 노란색은 서로 다르므로, 인식은 실제 영상 색상에 맞췄어.

RGB-D 영상의 색상과 깊이, 카메라 보정 정보, SLAM 좌표를 이용해 접근 위치를 구해.
가제보 실제 물체 좌표를 탐지 입력으로 사용하지 않아.
열쇠 가까이에 도착해 영상을 다시 확인한 후 블록을 위로 옮겨 시뮬레이션 획득을 표현해.
획득을 확인해야 문 열기가 가능하고, 문은 위로 들어 올리는 방식이야.
문 이동 응답 후 라이다에서 앞 공간이 비었다는 것까지 확인해야 완료해.

색상 규칙은 현재 미로에 맞춰져 있어. 다양한 열쇠 형태를 학습한 객체 검출 모델은 아니야.
임무에는 출발점 복귀 동작을 사용하지 않아.

## 검사

프로젝트 폴더에서 실행해.

```bash
python3 -m unittest discover -s tests -v
```

검사는 지도 좌표·프론티어·경로 판정, 비동기 요청 취소, 영상 색상·깊이·좌표 변환,
열쇠 없는 문 열기 차단, 문 열림 확인과 설정의 일관성을 다뤄.

`logs/`와 카메라 로봇 생성물, 개인 백업·업데이트 압축 파일은 Git에 올리지 않아.
ROS 통신은 프로젝트 스크립트에서 `ROS_DOMAIN_ID=26`, 가제보 통신 공간은 `maze_escape`를 사용해.
