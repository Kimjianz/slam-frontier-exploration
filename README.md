# maze_escape — SLAM 기반 미로 탐색과 카메라 열쇠·문 제어

TurtleBot3가 SLAM 지도를 생성하고, 직접 구현한 프론티어 알고리즘으로 미지 영역을 자율 탐색하는 프로젝트입니다.
RGB-D 카메라로 열쇠 대용 물체를 인식·획득한 뒤 문으로 이동해 통로를 여는 과정을 구현했습니다.

## 현재 진행 상황

| 기능 | 확인 상태 |
|---|---|
| 팀 미로에서 TurtleBot3 실행 | 우분투 VM에서 실행 확인 |
| SLAM 지도 생성 | 정상적으로 그려지는 것 확인 |
| Nav2 왕복 이동 | 두 목표 이동 성공 |
| 직접 구현한 프론티어 추출·선택·반복 탐색 | 목표 10개 연속 도착 성공 |
| RGB-D 카메라 영상 수신·열쇠 인식 | 우분투 VM·가제보에서 실행 확인 완료 |
| 열쇠 접근·획득·문으로 이동 | 통합 실행 확인 완료 |
| 문 열기·라이다로 문 열림 확인 | 통합 실행 확인 완료 |

현재 미로에서 **자율 탐색 → 카메라 열쇠 인식 → 접근·획득 → 문으로 이동 → 문 열림 확인**까지 통합 실행을 확인했습니다.
로직·설정 자동 검사 44개도 통과했습니다. 탐색 목표 10개 도착은 반복 탐색의 검증 결과이며, 전체 영역 탐색률과는 구분합니다.

## 개발 환경

- Ubuntu 24.04 / ROS 2 Jazzy / Gazebo Harmonic
- TurtleBot3 Burger / SLAM Toolbox / Nav2
- Python 3.12, NumPy, OpenCV, PyYAML
- VMware 기반 개발

## 설치와 실행

ROS·가제보·TurtleBot3 패키지가 설치된 우분투에서 실행합니다.
저장소 폴더를 `~/maze_escape`로 두면 상세 안내의 경로를 그대로 사용할 수 있습니다.
실행 스크립트는 실제 프로젝트 폴더 위치를 자동으로 찾습니다.

```bash
cd ~/maze_escape
bash setup.sh
```

`setup.sh`는 설치된 패키지를 확인하고, 프로젝트의 `models/camera_burger` 안에 RGB-D 카메라 로봇을 생성합니다.
설치된 로봇 모델과 바퀴·마찰·주행 물리 설정은 유지합니다.

각각 별도 터미널에서 실행하며, 앞 단계가 준비된 뒤 다음으로 진행합니다.

| 터미널 | 명령 | 역할 |
|---|---|---|
| 1 | `bash run/01_sim.sh` | 가제보 미로·카메라 로봇·센서 연결 |
| 2 | `bash run/02_slam.sh` | SLAM 지도 생성 |
| 3 | `bash run/03_nav2.sh` | 자율 이동 |
| 4 | `bash run/04_rviz.sh` | 지도·로봇·카메라 화면 |
| 5 | `bash run/05_probe.sh` | 짧은 왕복 이동 시험 |

왕복 시험을 통과하면 같은 터미널 5에서 아래 프로그램 중 하나를 실행합니다.

```bash
# 프론티어 표시 확인: 종료할 때 Ctrl+C
bash run/06_frontiers.sh

# 프론티어 자동 탐색만 시험
bash run/07_explore.sh

# 카메라로 열쇠 획득 후 문 열기
bash run/08_camera_escape.sh
```

06·07·08은 한 번에 하나씩 실행합니다. 자세한 준비·종료 방법은 아래 문서를 참고하세요.

- [처음 실행하기](처음_실행하기.md)
- [카메라 열쇠 인식과 문 열기](카메라_열쇠와_문_실행하기.md)

## 카메라 임무

현재 미로는 **노란색 블록을 열쇠 대용 물체**, **빨간색 벽을 문**으로 사용합니다.
열쇠 물체의 모델 이름은 `red_key`이지만 실제 표시 색상은 노란색이며, 영상 인식은 이 색상을 기준으로 합니다.

RGB-D 영상의 색상·깊이, 카메라 보정 정보, SLAM 좌표를 이용해 접근 위치를 계산합니다.
열쇠 가까이에 도착해 영상을 다시 확인한 후 블록을 위로 옮겨 시뮬레이션에서 획득을 처리합니다.
획득을 확인해야 문 열기가 가능하며, 문은 위로 들어 올리는 방식으로 열립니다.
문 이동 명령의 응답과 함께 라이다에서 앞 공간이 비었다는 것까지 확인한 뒤 임무를 완료합니다.

현재 미로의 색상 규칙을 이용하는 인식 방식이며, 인식 입력은 카메라 영상입니다.
다양한 열쇠 형태를 학습한 객체 검출 모델과는 구분됩니다.

## 검사

프로젝트 폴더에서 실행합니다.

```bash
python3 -m unittest discover -s tests -v
```

검사는 지도 좌표·프론티어·경로 판정, 비동기 요청 취소, 영상 색상·깊이·좌표 변환,
열쇠 없는 문 열기 차단, 문 열림 확인과 설정의 일관성을 검증합니다.

`logs/`와 카메라 로봇 생성물, 개인 백업·업데이트 압축 파일은 Git에서 제외합니다.
ROS 통신은 `ROS_DOMAIN_ID=26`, 가제보 통신 공간은 `maze_escape`를 사용합니다.
